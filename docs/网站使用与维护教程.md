# 第 1 章　先花 3 分钟看懂它怎么运转

## 1.1 你要记住三个地址

| 名称 | 地址 | 用来做什么 |
| :--- | :--- | :--- |
| **网站** | `https://2019527.xyz` | 读者看的页面 |
| **仓库**（放文章的"库房"） | `https://github.com/wangzhiman123/blog` | 你改文章的地方 |
| **仓库设置** | 仓库页面顶部 `Settings` | 改域名、看部署状态 |

> 现在网站打不开是**域名还没实名认证**，和你的操作无关。文章照常上传，域名通了会自动全部显示。

## 1.2 它是怎么运转的

```
你在仓库里改了一个文字文件
        ↓  点 Commit（提交）
GitHub 收到通知，自动开工（1～3 分钟）
        ↓
它把文字 + 主题 + 图片"编译"成网页
        ↓
网站更新，读者看到新内容
```

**关键认知：你写的不是网页，是文字稿。** 网页由 GitHub 自动生成，所以：

- 你**永远不会**直接改网页文件（那个叫 `public/` 的文件夹是自动生成的，改了也会被覆盖）
- 每次提交都会**自动**重新生成，不需要点任何"发布"按钮

## 1.3 一个必须知道的规则

文章写错字、格式乱，网站**不会崩**；但**日期填成未来**，那篇文章就**不会出现**（第 3.3 节细说）。
这两个是最容易让人以为"我传了但没生效"的原因。

# 第 2 章　目录地图：哪个文件夹管什么

打开仓库，根目录会看到这些文件夹。**只有前三个是你需要动的**。

| 文件夹 / 文件 | 是什么 | 你能动吗 |
| :--- | :--- | :--- |
| `content/posts/` | **所有文章**，一篇一个文件夹 | ✅ 天天动 |
| `static/images/` | 你自己的图片（头像、文章配图） | ✅ 可以加 |
| `data/friends.yml` | 友情链接名单 | ✅ 可以加 |
| `config/` | 网站的各种设置（标题、菜单、评论…） | ⚠️ 照教程改，别乱删 |
| `docs/` | 说明书（本文件就在这） | 看，不用改 |
| `themes/` | 主题（FixIt），相当于网站的"皮肤" | ❌ 别碰 |
| `layouts/`、`assets/` | 我给网站写的定制模板和样式 | ❌ 别碰，改坏会白屏 |
| `public/` | 自动生成的网页 | ❌ 别碰，每次都会被覆盖 |

# 第 3 章　上传一篇新文章（主流程）

整个过程 **8 步**，熟练后 10 分钟能写完一篇。

## 3.0 先打开写作助手

**网址：`https://2019527.xyz/tools/xiezuo.html`**

（域名还没通之前，用仓库里这个文件也行：`fixit-site/tools/写作助手.html`，双击打开即可。）

它长这样：左边填内容，右边实时出现"最终格式"，底部有按钮。**它不联网，你填的东西不会上传到任何地方。**

## 3.1 填标题

在「标题」框里写文章大标题，就是网站上显示的那行字。

- 中文标点照常用（问号用「？」）
- 标题里有冒号也没关系，助手会自动加引号保护

## 3.2 填「网址目录名」

这一栏决定文章的网址，**只能是英文小写字母、数字、短横线**。

| 你填 | 文章网址 |
| :--- | :--- |
| `dingjin-tuihuan` | `https://2019527.xyz/posts/2026-10-30-dingjin-tuihuan/` |

规则三条：

1. 用英文或拼音，多个词之间用**短横线** `-`，不要空格
2. 不要用中文（技术上能用，但分享到微信会变成一长串乱码，很难看）
3. 一旦发布就不要再改，改了旧链接会失效

> 助手会自动纠错：你写了大写、空格、中文标点，它会立刻改成规范写法。

## 3.3 选日期 —— 这里最容易出错

日期就是文章在列表里的排序依据（越新越靠前）。

**⚠️ 千万不要填今天以后的日期。** 我实测过：日期填明天，GitHub 上显示发布成功，但网站上根本找不到这篇文章（Hugo 默认不发布未来日期的文章）。助手会检测到并弹红字提醒你。

时间默认 `09:00`，不用改。

## 3.4 分类和标签

- **分类**：写 1～2 个，**顺序很重要**——第一个是一级分类，第二个是二级分类：

  ```yaml
  categories:
  - 工作        # 一级
  - 案例复盘    # 二级，挂在「工作」下面
  ```

  顶部菜单的「分类 ▾」下拉、`/categories/` 分类页、文章页的分类层级都会
  **自动同步**：写一个新的栏目名，网站会自动多出一组；写一个新的细分名，
  会自动挂到对应大类下面，不用再去改任何配置文件。
  现有大类：`工作`、`学习`、`生活`、`其他`。想给新分类换图标、加说明或调整
  显示顺序，才需要编辑 `data/categories.yml`（可选）。

- **标签**：可以多写几个，用逗号分隔。标签是给读者筛文章用的，写具体一点（`定金`、`商品房`）比写空泛的（`法律`）有用。

## 3.5 摘要（选填，但强烈建议填）

用一到三句话说清"这篇文章解决什么问题"。它会显示在首页文章列表里，也影响搜索引擎。

不填也能用，主题会自动截取正文开头，但经常截得很难看。

## 3.6 封面图（选填）

填一个 `https://` 开头的图片地址。它会同时成为**首页列表缩略图**和
**微信分享卡片**的图。

写作助手会自动把它写进表头的两个字段：`featured_image_preview`（管首页缩略图）
和 `images`（管微信分享图，要写成列表）。旧写法 `featuredImage` 已失效，别再用。

没有合适的图就留空，不影响发布；表头里这两行会写成 `""`，站点用头像兜底。

## 3.7 写正文

正文只用 6 种写法就够了：

| 想实现 | 就这样写 | 注意 |
| :--- | :--- | :--- |
| 另起一段 | 段落之间**空一行** | 不空行会连成一段 |
| 小标题 | `## 一、小标题` | 两个井号**加一个空格** |
| 加粗 | `**重点**` | 前后各两个星号 |
| 列表 | `- 第一项`（每行一个） | 短横线**加空格** |
| 引用法条 | `> 引用的内容` | 大于号加空格 |
| 插图 | `![说明文字](https://图片地址)` | 方括号是说明，圆括号是地址 |

**三个常见错误**（会让格式乱掉）：

1. 小标题写成 `##小标题`（漏了空格）→ 会原样显示成 `##小标题`
2. 加粗只写一个星号 `*重点*` → 变成斜体
3. 复制 Word 里的内容带进来一堆隐藏格式 → **先在记事本里粘一遍，再复制到助手**

## 3.8 生成并上传（关键 4 步）

**第 1 步**：点右边的 **「复制全文」**，按钮下会出现绿字「已复制」。

**第 2 步**：点 **「去 GitHub 新建这篇文章」**。它会自动打开 GitHub 的"新建文件"页面，并且**文件名已经帮你填好了**（`content/posts/2026-10-30-dingjin-tuihuan/index.md`）。

如果浏览器提示要登录 GitHub，登录一次即可。

**第 3 步**：在页面中间的大白框里点一下，粘贴（`Ctrl + V`；Mac 用 `Cmd + V`）。
粘贴成功后，框里会出现以 `---` 开头的一大段文字。

**第 4 步**：拉到页面最底部，点绿色按钮 **`Commit changes...`**，弹窗里什么都不用改，再点一次 **`Commit changes`**。

> 到这一步就结束了。1～3 分钟后网站自动更新。

## 3.9 怎么确认成功了

**看机器有没有干活**：打开仓库页面 → 点顶部 **`Actions`** → 左侧点 **`Hugo build and deploy`** → 看最上面那条：

| 看到 | 含义 |
| :--- | :--- |
| 🟡 黄色圆点转圈 | 正在生成，等 1～3 分钟 |
| ✅ 绿色勾 | 成功，网站已更新 |
| ❌ 红色叉 | 失败了，点进去看红色那行，把截图发我 |

**看文章**：打开 `https://2019527.xyz/posts/你的目录名/`。

## 3.10 传了但网站没有？按顺序排查

| 检查 | 怎么查 |
| :--- | :--- |
| ① 部署成功了吗 | Actions 里是绿勾还是红叉 |
| ② 日期是未来吗 | 打开文章文件，看 `date:` 那一行是不是今天以后 |
| ③ 是不是草稿 | 文件里有 `draft: true` 就不会发布，删掉这行 |
| ④ 文件夹位置对吗 | 必须是 `content/posts/xxx/index.md`，不能直接放 `content/` 下 |
| ⑤ 浏览器缓存 | 按 `Ctrl + F5` 强制刷新 |

# 第 4 章　不用助手，手写一篇

如果你在外面用别人的电脑、只想快速发一篇，可以跳过助手，直接用这个模板。

在仓库里：`Add file` ▾ → `Create new file` → 文件名填 `content/posts/2026-10-30-wenzhang/index.md` → 粘贴下面内容 → 改成你的 → 提交。

```yaml
---
title: "文章标题写这里"
date: 2026-10-30T09:00:00+08:00
categories:
- 工作          # 一级分类
- 案例复盘      # 二级分类；换成新名字，页面会自动同步
tags:
- 标签一
- 标签二
summary: "一两句话摘要。"
featured_image_preview: ""
images: ""
authors:
- 王志满律师
---

正文第一段。

## 一、小标题

正文内容。
```

## 字段说明

| 字段 | 必填 | 说明 |
| :--- | :--- | :--- |
| `title` | ✅ | 文章标题，含冒号/引号时用英文双引号包住 |
| `date` | ✅ | 格式固定 `年-月-日T时:分:秒+08:00`，`+08:00` 是北京时间，别删 |
| `categories` | 建议 | 每行一个 `- 分类名`；第一个是一级、第二个是二级，新名字会自动同步到菜单和分类页 |
| `tags` | 建议 | 下面每行一个 `- 标签名` |
| `summary` | 建议 | 列表页摘要；不写则自动截取正文 |
| `authors` | 建议 | 固定写 `- 王志满律师`（**一个字都不能差**，否则作者页会裂成两个） |
| `featured_image_preview` | 选填 | 首页列表缩略图，只认这个下划线写法（旧名 `featuredImage` 已失效） |
| `images` | 选填 | 微信分享图，必须写成列表：下一行 `- "图片地址"` |
| `weight` | 选填 | 写 `-1` 表示**置顶**（我实测有效，会排在所有文章最前） |
| `draft` | 选填 | 写 `true` 表示草稿，不发布 |

**格式铁律**：文件**第一行必须是 `---`**，front matter 结束也要一行 `---`，中间每行都是 `字段: 值`（冒号后面**有一个空格**）。

**封面图那两行**：空着 `""` 就是没封面图，站点自动用头像。要补图时，
`featured_image_preview` 把网址填进引号；`images` 要改成两行的列表
（`images:` 换行 `- "网址"`），**不能**把网址直接塞进 `images: ""` 的引号里。

# 第 5 章　改文章、删文章、撤回

## 5.1 从网址找到文件

文章的网址和文件夹是对应的：

```
https://2019527.xyz/posts/2026-10-30-dingjin-tuihuan/
                                 └──────┬──────┘
              仓库里就是 content/posts/2026-10-30-dingjin-tuihuan/index.md
```

## 5.2 修改正文

1. 仓库里进入 `content/posts/` → 点那个文件夹 → 点 `index.md`
2. 点右上角**铅笔图标**（`Edit this file`）
3. 改文字
4. 拉到底点 `Commit changes...` → 再点 `Commit changes`

改完 1～3 分钟网站自动更新。

## 5.3 改日期会发生什么

日期决定排序。把日期改新，文章会跳到列表最前面；改旧，会沉下去。**已发布的文章一般不用改日期**，除非你确实写错了。

## 5.4 删除一篇文章

1. 进入 `content/posts/` → 点那篇文章的**文件夹**
2. 点右上角 `...`（三个点）→ `Delete directory`
3. 点绿色 `Commit changes`

> ⚠️ 删了就没了（历史记录里还能找回，见 5.5）。评论和阅读量会一起消失。

## 5.5 改错了怎么撤回

**方法一（最稳）**：仓库首页 → 点 `Commits`（提交记录）→ 找到你刚才那次提交 → 点进去 → 右上角 `...` → `Revert` → 提交。
效果：把那次改动整体撤销。

**方法二（改单篇）**：进入那个文件 → 点右上 `History` → 找到上一次正常的版本 → 复制里面的内容 → 回编辑器粘贴覆盖。

# 第 6 章　图片怎么加

## 6.1 三种方式，按需选

| 方式 | 适合 | 难度 |
| :--- | :--- | :--- |
| A. 网络图片链接 | 用别人图床、官方截图 | ⭐ 最简单 |
| B. 上传到自己网站 | **推荐**，自己的照片、扫描件 | ⭐⭐ |
| C. 和文章放同一个文件夹 | 一篇有很多图时整齐 | ⭐⭐⭐ |

## 6.2 方式 A：网络图片

在正文里写：

```markdown
![示意图](https://example.com/photo.jpg)
```

地址必须是 `https://` 开头，并且**直接粘到浏览器地址栏能打开图片**（不是打开一个网页）。

## 6.3 方式 B：上传到 static/images（推荐）

**上传：**

1. 仓库里进入 `static/images/`
2. 右上 `Add file` ▾ → `Upload files`
3. 把图片拖进去（文件名建议改成英文，例如 `2026-dingjin-01.jpg`）
4. 拉到底点 `Commit changes`

**引用：**

```markdown
![定金纠纷示意图](/images/2026-dingjin-01.jpg)
```

注意是 `/images/...`，**不是** `/static/images/...`。

**当封面图**：把同样的地址填在 front matter 的 `featured_image_preview:` 后面；
微信分享卡片另用 `images:`（写成列表，见第 4 章「字段说明」）。
用写作助手时填一次「封面图网址」，两处会自动写好。**旧字段 `featuredImage` 已失效**。

## 6.4 图片建议

- 宽度 1000～1600 像素足够，太大加载慢
- 格式用 `.jpg`（照片）或 `.png`（截图、图表）
- 单张控制在 500KB 以内
- 文件名用英文和短横线，别用中文和空格

# 第 7 章　改网站设置

## 7.1 总表：想改什么，去哪个文件

所有设置文件都在 `config/` 下。**在仓库里打开文件后，用浏览器搜索（`Ctrl + F`）关键词**，比记行号靠谱。

| 想改 | 文件 | 搜索关键词 |
| :--- | :--- | :--- |
| 网站标题（浏览器标签） | `config/production/hugo.toml` | `title` |
| 首页大标题 / 副标题 | `config/_default/params.toml` | `[home.profile]` |
| 头像 | `static/images/avatar.jpg`（换文件） | — |
| 页脚运行天数 | `config/_default/params.toml` | `[footer.site_time]` |
| 页脚社交图标 | `config/_default/params.toml` | `[social]` |
| 友情链接 | `data/friends.yml` | — |
| 顶部菜单 | `config/_default/menus.toml` | `[[main]]` |
| 评论开关 | `config/_default/params.toml` | `[comment]` |
| 首页显示几篇 | `config/_default/params.toml` | `[home.posts]` 附近的 `paginate` |

改完都是同一套收尾动作：拉到底 → `Commit changes...` → `Commit changes`。

> **友情链接不用手写代码**：打开 `https://2019527.xyz/tools/youlian.html`，
> 粘贴网址就能自动生成代码，还能一键打开后台文件，详见 7.6。

## 7.2 改网站标题

`config/production/hugo.toml` 第 1 行：

```toml
title = "王志满律师"
```

顺带说一句：语言文件 `config/_default/languages.toml` 里还有两个 `title`（第 17 行中文、第 25 行英文），那是各语言站自己的标题。**两处都改才彻底。**

## 7.3 改首页头像和资料卡文字

`config/_default/params.toml`，搜 `[home.profile]`：

```toml
avatar_url = "/images/avatar.jpg"          # 头像
title = "王志满律师"                        # 首页大标题
subtitle = "民事诉讼 · 行政诉讼 · 司法案例研究"   # 副标题
```

**换头像图片**：进 `static/images/`，把新照片命名为 `avatar.jpg` 上传，选择覆盖。不用改任何配置。

## 7.4 改页脚「已运行 N 天」的起点

`config/_default/params.toml`，搜 `[footer.site_time]`：

```toml
value = "2019-05-27T00:00:00+08:00"
```

- 这个日期是**起点**，天数由浏览器实时算出来：今天是 2026-10-29，显示 2712 天
- 想让它从今天开始算 → 改成 `2026-10-29T00:00:00+08:00`，立刻变成 0 天
- 想整块隐藏 → 上面的 `enable = false`
- 想关掉心跳动画 → `animate = false`

## 7.5 改页脚社交图标

`config/_default/params.toml`，搜 `[social]`：

```toml
GitHub = "wangzhiman123"      # 填账号名即可
Zhihu = "pxpiloveu"
Bilibili = "35768392"
WeChat = { url = "https://mp.weixin.qq.com/s/xxx", title = "微信公众号", icon = { class = "fa-brands fa-weixin" } }
```

不想显示某个 → 把值改成 `""`。想加新的（比如邮箱）→ 照格式加一行。

### 生成的代码长什么样

```yaml
- nickname: "某某的博客"
  url: "https://example.com"
  description: "写点法律与生活的记录"
  avatar: "https://example.com/logo.png"
  group: blogs
  weight: 50
```

- `nickname` 和 `url` 必填，`url` 要带 `https://`
- `group` 决定放在哪一栏（博友 / 常用工具 / 官方检索 / 博客圈），在工具里下拉选，不用手写
- `weight` 越大越靠前；同一分组里跟写在文件第几行无关，所以**直接粘到末尾最省事**
- 头像填对方的图片外链即可，不用下载到仓库；留空时工具会自动补 `favicon.ico`
- 每条的 `-` 要顶格，下面的字段前面空两格（工具已经排好，别手动改缩进）

> 原来的独立页面（友链代码转换器）已删除，功能都在这里；
> 收藏过旧地址的，请改收藏上面的新网址。

# 第 11 章　这些不要碰

| 别动 | 后果 |
| :--- | :--- |
| `themes/` 里的任何文件 | 主题坏了整站白屏，且升级会覆盖你的修改 |
| `layouts/`、`assets/scss`、`assets/js/modules` | 我写的定制模板，改错会白屏 |
| `.github/workflows/` | 自动部署流程，改错就不自动发布了 |
| `config/production/hugo.toml` 里的 `baseURL` | 写错会让全站样式和链接失效 |
| 根目录的 `public/` | 自动生成，改了白改 |
| 文章文件夹的**名字** | 它就是网址，改名等于旧链接全部失效 |

**万一改坏了**：别慌，用 5.5 节的 Revert 撤回，或者直接告诉我改了什么，我帮你恢复。
