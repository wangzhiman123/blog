# 站点功能配置说明

本次新增的功能都走主题内置能力或 `custom_partials` 注入点，没有改动主题文件，
所以升级主题不会冲突。要改哪一项，按下面的位置找即可。

---

## 1. 头像与 favicon

| 项目 | 位置 |
| :--- | :--- |
| 头像源文件 | `static/images/avatar.jpg`、`assets/images/avatar.jpg`（两份内容相同） |
| 首页资料卡 | `config/_default/params.toml` → `[home.profile]` 的 `avatar_url`、`title`、`subtitle` |
| 页脚/文章作者头像 | 同文件 `[author].avatar` |
| favicon | `static/favicon.ico`、`favicon-16x16.png`、`favicon-32x32.png` |
| iOS 主屏图标 | `static/apple-touch-icon.png`（180×180） |
| Android 图标 | `static/android-chrome-192x192.png`、`-512x512.png` |
| Safari 固定标签 | `static/safari-pinned-tab.svg` |

换头像时重新生成对应尺寸即可，尺寸与文件名不要改，主题按固定路径引用。

## 2. Twikoo 评论

`config/_default/params.toml`：

```toml
[comment]
enable = true

[comment.twikoo]
enable = true
env_id = "https://twikoo.2019527.xyz"   # 复用原站自建服务
visitor = true        # 文章阅读量
comment_count = true  # 文章讨论量
```

- 评论数据与原站（2019527.xyz）共用同一个 Twikoo 服务，但按页面路径分区，
  所以新站是独立的一套评论，不会和旧站串。
- 换服务只需改 `env_id`，自建服务填地址，腾讯云开发填环境 ID。

## 3. 阅读量 / 讨论量

- **阅读量**：文章页 `#twikoo_visitors`，由 Twikoo 按路径计数，显示为「N 次阅读」。
- **讨论量**：文章页 `#twikoo-comment-count`，显示为「N 条评论」。
- 两者都要求 `[comment].enable = true`（已在上面开启）。

## 4. 页眉数据看板

模板：`layouts/_partials/custom/header-stats.html`（桌面）、
`header-stats-mobile.html`（移动端），挂载在 `[custom_partials]` 的
`menu_desktop` / `menu_mobile`。

| 指标 | 算法 |
| :--- | :--- |
| 文章数 | `posts` 区文章条数 |
| 字数 | 所有文章 `WordCount` 求和，≥1 万显示为「12.3 万字」 |
| 图片数 | 正文中 `![]()`、`<img>`、`{{< image >}}` 三种写法求和 |
| 视频数 | 正文中 `{{< youtube/bilibili/vimeo/video >}}`、`<video>` 求和 |
| 访问量 | 不蒜子全站 PV，由 `assets/js/custom.js` 从页脚镜像过来 |

前四项在**构建时**算好，是静态数字，打开即显示；
访问量是运行时数据，加载后约 0.5 秒填入。

排序规则改了也能自动跟上——它们直接遍历内容，不需要手工维护数字。

## 5. 页脚：运行天数、总访问量、总访客数

`config/_default/params.toml`：

```toml
[footer.site_time]
enable = true
value = "2019-05-27T00:00:00+08:00"   # 起点日期，据此算"已运行 N 天"
```

改 `value` 就能改天数；当前取的是最早一篇文章的日期。天数由浏览器在页面加载时用
「今天 − value」算出来，不是写死的数字，所以改完日期就自动变成新的天数，不用管别的。

其他可用开关：`enable = false` 整块隐藏、`animate = false` 关掉心跳动画、
`icon` 换图标、`pre` 在数字前加固定文字。

> 显示格式：主题原本输出 `2712, 23:30:12`（纯数字 + 逗号，容易被误读成时间）。
> 本项目把这一行的格式改成 `2712 天 23:30:12`，实现方式是在
> `assets/js/modules/misc.ts` 放了一份只改这一个字符串的副本，覆盖主题同名文件。
> **升级主题时**，如果主题改了这个模块，需要把副本重新复制一次再改这一行，
> 否则会一直用旧版逻辑（不影响其他功能，只是运行天数的写法会退回主题默认）。

总访问量 / 总访客数用的是主题自带的不蒜子（`[busuanzi] enable = true`），
默认只显示图标和数字。`assets/scss/custom.scss` 里用 `::before` / `::after`
给它们补了「总访客 N 人」「总访问 N 次」的中文标签——只加文字，不产生第二份统计。

## 7. 友情链接

| 项目 | 位置 |
| :--- | :--- |
| 页面 | `content/friends/index.md`（`layout: friends`，旧地址 `/links/` 自动跳转过来） |
| 数据 | `data/friends.yml` |
| 模板 | `layouts/friends.html`（覆盖主题）+ `layouts/_partials/custom/friend-card.html`（单张卡片） |
| 样式 | `assets/scss/custom.scss` 末尾「友链页」段 |
| 脚本 | `assets/js/custom.js` 的 `initFriendSearch()` / `initFriendAvatarFallback()` |
| 菜单入口 | `config/_default/menus.toml` 里 `identifier = "friends"` |

`data/friends.yml` 每条支持的字段：

| 字段 | 必填 | 说明 |
| :--- | :--- | :--- |
| `nickname` | 是 | 站点名称 |
| `url` | 是 | 站点地址 |
| `description` | 否 | 一句话简介，同时用于悬停提示与搜索 |
| `avatar` | 否 | **直接填对方的图片外链**，不要把图片下载进仓库；留空显示默认头像 |
| `avatar_fit` | 否 | `cover`（默认，裁切填满）/ `contain`（完整显示，给横向长条 logo 用） |
| `group` | 否 | 分组 key，与页面 front matter 的 `friend_groups[].key` 对应 |
| `weight` | 否 | 组内排序，越大越靠前 |

**头像为什么不用本地文件**：友链是别人的站点，头像属于对方的品牌资源。存一份到自己仓库，
既平白增加体积，又会在对方换 logo 之后变成过期图片。直接引用外链，对方更新这边自动跟着变。
两个配套措施兜住风险：`referrerpolicy="no-referrer"` 绕过一部分防盗链；加载失败时
`initFriendAvatarFallback()` 把图片换成内置的默认头像，不会出现破图图标。

**分区怎么加**：页面 front matter 里写一组

```toml
[[friend_groups]]
key = "blogs"
name = "博友"
desc = "长期交流、内容值得一读的个人博客"
```

`key` 与数据里的 `group` 对上就行，顺序即页面上从上到下的顺序。没写 `group` 的条目
会落到最后的「其他站点」，不会丢。

`friend_scheme` 三种排版：`mahjong`（方形卡片）、`domino`（横条，当前使用）、`note`（无头像）。

## 10. 导航下拉菜单（分类 ▾）

主菜单现在是「归档 / 分类 ▾ / 标签 / 友链 / 关于」：

```
归档
分类 ▾  →  工作、学习、生活
标签
友链
关于
```

桌面端**鼠标移到「分类」上就自动展开三个一级分类**，触屏点一下展开。
改菜单只动一个文件：`config/_default/menus.toml`。

层级的做法是给子项写 `parent`：

```toml
[[main]]
identifier = "categories"     # 父项的 id
name = "分类"
url = "categories/"
weight = 2

[[main]]
identifier = "cat-work"
parent = "categories"         # 挂到「分类」下面
name = "工作"
pageRef = "/categories/工作"   # 让 Hugo 自己解析中文路径
url = "categories/工作/"       # 兜底
weight = 1
```

注意五点：

1. **最多两层**，主题不支持三级菜单；
2. `weight` 只在同一层内排序，父项之间的顺序看父项自己的 `weight`；
3. 子项是中文分类名，**必须写 `pageRef`**（`/categories/工作` 这种），Hugo 会把它
   解析成正确的百分号编码地址；只写中文 `url` 有时会 404；
4. 每项前面的图标来自 `[main.params] icon`，用的是 Font Awesome 类名
   （`fa-solid fa-briefcase` 这种）；
5. **增删一级分类要同步改两处**：`data/categories.yml` 里加上分类树，
   `menus.toml` 里加上对应的子项，否则下拉里会缺一项。

移动端不用另外配，主题会自动把子菜单做成点击展开的折叠项。

三个独立页面，不在「文章」列表里，地址固定：

改内容就是改这三个 md 文件，用普通 Markdown 写，保存推送即可。几个约定：

## 12. 备案号（预留位，现在不显示）

站点现在托管在 **GitHub Pages**（境外），不需要备案，所以页脚没有备案信息，也不会
留出一行空白。

以后如果迁到国内服务器（阿里云 / 腾讯云等），备案下来之后**只改一处**：

`config/_default/params.toml` → 搜 `gov = ""` 和 `icp = ""`，填上即可。

```toml
# ICP 备案号
icp = '<a href="https://beian.miit.gov.cn/" target="_blank" rel="noopener noreferrer">赣ICP备2026000000号-1</a>'

# 公安网安备案号（图标先放到 static/images/gongan-beian.png）
gov = '<a href="https://beian.mps.gov.cn/#/query/webSearch?code=36010000000000" target="_blank" rel="noopener noreferrer"><img src="/images/gongan-beian.png" alt="公安备案" width="14" height="14" style="vertical-align:-2px" /> 赣公网安备 36010000000000 号</a>'
```

几个要点：

1. 值必须用**单引号**包起来（里面是 HTML，有双引号，用双引号会打架）；
2. **只填一个也行**，另一个留空不影响；两个都空，整行自动隐藏；
3. 公安备案图标去 `beian.mps.gov.cn` 下载，重命名成 `gongan-beian.png` 放进
   `static/images/`；
4. 填完保存 → 推送 → 等 Actions 跑完，页脚就出现了，不需要改模板；
5. 备案号必须与工信部 / 公安系统登记的完全一致，页面底部要能点进查询页。

> 提醒：国内服务器除了备案，还要求网站内容合规、页面底部展示备案号并链接到
> `beian.miit.gov.cn`。这一步别用别人的号，被查到会直接关站。

## 13. Cookie 弹窗（已关闭）

主题自带一个右下角 Cookie 授权条，现在已经关掉：`config/_default/params.toml` 里的

```toml
[cookieconsent]
enable = false
```

**为什么可以关**：本站只有一个「不蒜子」访问计数脚本，没有广告、没有用户画像、
没有跨站追踪，不属于必须弹窗单独征得同意的情形。读者想了解细节，隐私政策第三节
已经写清楚了（统计脚本写入什么、评论记录什么 IP、保存多久）。

**什么时候要打开**：如果以后接入百度联盟、Google AdSense 这类广告，或者加了
任何跨站追踪 / 再营销脚本，就把 `enable` 改回 `true`，右下角会重新出现授权条。

## 14. 分享缩略图（微信 / QQ / 微博）

分享链接时显示的那张小图，取值有三层优先级：

1. 文章 front matter 里的 `images`（或 `featuredImage` / `cover`）；
2. 文章正文第一张图（首页卡片取缩略图用的也是它）；
3. 兜底：`config/_default/params.toml` 里的 `images`

```toml
images = ["/images/avatar.jpg"]
```

**现在兜底用的是站点头像**（`static/images/avatar.jpg`，336×336 正方形）。微信、QQ
的链接卡片本来就是方图，用头像辨识度最高；`/images/og-default.png` 那张 1200×630
的文字卡片还留在仓库里，想换回去就把 `images` 改回 `["/images/og-default.png"]`。

写新文章时建议：

- 自己配一张图，别落到兜底（兜底是头像，和文章内容无关）；
- 尺寸 1200×630 或正方形都行，微信会自己裁；
- 文件名用英文或数字，**别用中文**（个别平台的抓取器处理中文名会失败）；
- 同一张图同时写进 `featuredImage` 和 `images`，这样首页卡片和分享卡片一致。

## 15. 友链页的搜索框与申请模板

### 搜索框

搜索框由 `layouts/friends.html` 渲染，数据取自每张卡片的 `data-search` 属性
（站点名称 + 简介，构建时转小写）。过滤逻辑在 `assets/js/custom.js` 的
`initFriendSearch()`，纯前端，没有额外依赖，也不发请求。

- 单个关键词：包含匹配，「博客」能同时命中「若梦博客」「博友圈」这类；
- 多个关键词用空格分隔：取**交集**，「博 圈」只留标题或简介里两个词都出现的；
- 命中为零时显示空提示，并给一个跳到「申请友链」的锚点；
- 分区整组没命中会自动收起，避免留下一排空标题；
- 按 `Esc` 或点右侧叉号清空，右侧「共 N 个站点」会跟着变成「命中数」。

**样式里的一个坑**：主题给 `.friend-link` 设了 `display: flex`，会盖掉浏览器
`[hidden]` 的默认 `display: none`，所以 `custom.scss` 里必须用
`.friend-link[hidden] { display: none !important }` 提权，否则过滤看起来「没反应」。

### 申请模板

页面底部的「申请友链」是 `content/friends/index.md` 的正文，不是硬编码在模板里的，
想改措辞直接改 markdown。中间那段模板用无语言的代码块包着，主题会给它自动加复制按钮
（`CopyModule` 复制的是代码本身，不含行号），读者点一下就复制走了。

同时给了「添加本站」小节，把本站的名称、地址、简介、头像列好，方便对方直接抄。

### 搬运旧站友链时做的三件事

1. 逐条核对对方站点还能不能打开，`description` 按现行内容重写，不照抄旧文案；
2. 头像逐个试了 HTTP 状态与 Content-Type。**返回 `text/html` 的一律不用**
   （说明那个地址是 404 页面或单页应用外壳，放上去就是破图），
   这类站点改用默认头像，共 5 个：中国裁判文书网、Hugo、FixIt、Exyone's Blog、个人成长计划；
3. 横向长条 logo（若梦博客、BlogFinder、BlogsClub、博友圈、开往）标了
   `avatar_fit: contain`，否则圆形裁切后只剩一个字的宽度。

## 16. 工具页：HTML 转 Markdown

地址 `/tools/html2md.html`，单文件、纯前端、不依赖任何库，可以另存到电脑上双击打开，
和 `写作助手` 一样是「换台电脑也能用」的形态。

| 文件 | 说明 |
| :--- | :--- |
| `static/tools/html2md.html` | 全部内容都在这一个文件里（样式、转换器、界面逻辑） |

### 为什么不用 Turndown

Turndown 是主流方案，但要从 CDN 加载，断网或国内网络抽风就打不开，和「哪台电脑都能用」
的前提冲突。这里用浏览器自带的 `DOMParser` 把 HTML 解析成 DOM，再自己走一遍节点树输出
Markdown。`DOMParser` 生成的文档是惰性的，`<script>` 不会执行，比 `innerHTML` 安全。

### 转换范围

支持：标题、段落、粗体 / 斜体 / 删除线 / 高亮、行内代码、代码块（读 `language-xxx` 类名）、
链接、图片、有序 / 无序列表（含嵌套、`start` 起始序号）、引用（可嵌套）、GFM 表格
（含 `align` 对齐）、分隔线、定义列表、`<br>` 硬换行。

丢弃：`script` / `style` / `iframe` / `svg` / 表单控件、所有 `style` 与 `class` 属性、
`data:` 开头的 base64 图片、`javascript:` 伪链接。

### 三个容易踩的点

1. **`<br>` 不能直接输出 `"  \n"`**。收尾时会统一清掉行尾空白，硬换行会被一起吃掉。
   代码里用一个占位符 `\u0001`，清理完再还原成两个空格加换行。
2. **中文之间不该有空格**。网页源码为了折行插入的换行，转出来会变成「， 法院」这种。
   `collapseCJK()` 把「中文字符 + 空白 + 中文字符」中间的空白去掉；`<br>` 占位符不是
   空白字符，不会被误删。
3. **像标签的尖括号要转义**。文字里出现 `<div>` 这种，不转义会被渲染器当成 HTML 吞掉，
   所以只对「`<` 后面紧跟字母 / `/` / `!` / `?`」的情况加反斜杠，`5<10` 这种保持原样。

### 预览

右栏默认是「预览」，切到「源码」看 Markdown 原文。「预览」用 `mdToHtml()` 渲染 —— 一个
只覆盖本工具产出语法的小型解析器，保证预览里看到的就是复制出去之后的样子。
预览区空的时候显示图标 + 「转换后的 Markdown 将在这里预览」。

复制按钮在右栏右上角，降级顺序是：`navigator.clipboard` → `execCommand("copy")` →
都不行就自动选中结果并提示按 Ctrl+C（旧内核和不给剪贴板权限的浏览器上很常见）。
