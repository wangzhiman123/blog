能转什么

    

      
HTML结果

      
h1 ~ h6# ~ ######，勾「标题降一级」时整体下移

      
strong / b、em / i、del / s**粗**、*斜*、~~删~~

      
code、pre行内反引号；代码块自动识别 language-xxx 类名

      
a、img[文字](链接)、![说明](图片)

      
ul / ol 嵌套逐级缩进，有序列表保留 start 起始序号

      
blockquote> 引用，嵌套多层也对

      
tableGFM 表格，align 转成 :---: 对齐

      
hr、dl、figure---、定义列表、图注

    


    
故意不转的

    
    
      
  • script、style、iframe、svg、表单控件——直接丢弃，免得把脚本带进文章；
    • 
      
  • 内联的 style、class、id——Markdown 里没有对应写法，留着只会变噪音；
    • 
      
  • data: 开头的 base64 图片——转出来是一长串乱码，不如删掉；
    • 
      
  • javascript: 伪链接——只保留文字。
    • 
    


    
转完记得看一眼

    
    
      
  • 合并单元格（colspan / rowspan）Markdown 表达不了，会按第一列对齐，需要手工补；
    • 
      
  • Word 复制过来的内容常带一堆无意义嵌套，转完把多余空行删一删更清爽；
    • 
      
  • 图片若是对方站点的临时地址，发布前记得换成本地图片，否则过一阵会失效。
