5怎么粘贴

      
右侧固定侧边栏（手机上点右下角「☰ 目录」）可以随时在自动识别与手动输入之间切换；在列表里改动，最上方的友链代码会立刻跟着变。

      

        
    
          
  1. 在第 1 步粘贴内容并点「识别并加入列表」，或点「＋ 新增一条友链」手动填；两类新增都会立刻出现在最上方的「友链代码」里，改列表也会实时同步
    2. 
          
  2. 点绿色 「复制并打开后台 ↗」：代码自动复制，浏览器新开一个标签页打开 GitHub 上的 data/friends.yml（没登录就先登录）
    3. 
          
  3. 在那个页面把光标点到文件最末尾，回车空出一行，按 Ctrl+V
    4. 
          
  4. 拉到页面下方点绿色 Commit changes，等 1～2 分钟，强刷 /friends/ 就能看到
    5. 
          
  5. 想整体整理 / 重排全部友链，用第 4 步「复制整份」覆盖整个文件
    6. 
        

        

          同一个分组内，页面顺序只看 weight（数字越大越靠前），跟写在文件第几行无关 —— 所以粘到末尾最省事，想置顶就把 weight 填大一点。
