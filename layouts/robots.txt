# robots.txt —— 本站自建版本，覆盖主题 themes/FixIt/layouts/robots.txt
#
# 与主题原版的三个差别：
#   1. 不屏蔽 AI 爬虫（GPTBot / ClaudeBot / PerplexityBot / OAI-SearchBot 等），
#      目的是让 AI 助手在回答问题时能读取并引用本站文章；
#   2. 去掉主题硬编码的 Disallow: /*.md$，让每篇文章的 Markdown 纯净版可被抓取；
#   3. 修掉主题模板的换行问题 —— 原版会把 Sitemap 粘在上一行 Disallow 后面变成
#      "Disallow: /Sitemap: https://..."，导致 sitemap 声明失效。
#
# 仍然屏蔽的只有不产生读者、只抓数据的 SEO 监测类爬虫。
# 更新主题后如果访问 /robots.txt 发现又变回原样，说明本文件覆盖失效了。
# -------------------------------------------------------------------------------------
