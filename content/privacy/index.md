### 2. 自动获取的技术信息

**（1）访问日志**

本站是静态站点，页面文件托管在 **GitHub Pages** 上，由 GitHub 的服务器向您返回页面。在此过程中，托管服务商会自动生成访问记录，通常包含 IP 地址、浏览器与设备类型、访问时间、访问的具体页面、来源链接。这类日志主要用于排查故障、识别异常流量与攻击，本站不直接读取、也不单独留存这些日志。

**（2）不蒜子统计：会写入访客标识**

本站使用**不蒜子（Vercount）** 统计了解「哪些文章被读得多、读者从哪里来、页面打开是否顺畅」，用于在页面上显示文章的阅读次数与全站访问量。

它的工作方式很轻：页面加载时，浏览器向统计服务发起一次计数请求，服务端累加该页面的访问数字并返回。在此过程中，统计脚本会在您的浏览器**本地存储**中保存一个随机生成的访客标识，用于区分同一访客的重复访问，避免刷新一次就多计一次。

需要说明的是：这些标识**不包含**您的姓名、邮箱、身份证号，单独无法定位到具体某个人；但我们仍把它视为与您有关的信息，如实告知。

不蒜子（Vercount）由第三方提供，其自身的数据处理规则适用该服务自身的说明。

> **如何拒绝统计**：主流浏览器都可以在「设置 → 隐私与安全」中屏蔽第三方 Cookie 与站点数据，或直接使用无痕／隐私模式；也可以安装拦截统计脚本的浏览器扩展。拒绝后本站文章仍可正常阅读，不会有任何功能缺失，只是页面上不显示阅读量。

### 4. 评论服务的技术说明

本站评论功能使用 **Twikoo**，服务端部署在 **Vercel** 云函数上，评论数据存放于 **MongoDB Atlas** 数据库。

**评论时，您的 IP 地址会被记录。** 除此之外，服务端还会记录提交时间与浏览器信息（User-Agent），并与您填写的昵称、邮箱、网址、正文一并保存。

记录 IP 的用途只有两个：一是拦截垃圾评论与恶意灌水（同一来源短时间内大量发帖会被自动拦截），二是在出现攻击或纠纷时排查来源。**我们不会用 IP 地址做地域画像、广告定向，也不会将其用于对外展示。**

该服务及其数据库位于中国大陆境外，**您提交留言，即意味着上述信息（含 IP 地址）可能被传输至境外存储**。如果您不希望信息出境，请改用电子邮件与我们联系，我们同样会回复。
